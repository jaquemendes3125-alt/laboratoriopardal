🐍 Motor de Processamento — Google Colab

Automatize pesquisas — executa na nuvem do Google

import requests def pesquisar_molecula(nome): url = f"https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/{nome}/property/MolecularFormula,MolecularWeight,IUPACName/JSON" resp = requests.get(url) dados = resp.json() p = dados['PropertyTable']['Properties'][0] print(f"Nome: {p.get('IUPACName')}") print(f"Fórmula: {p.get('MolecularFormula')}") print(f"Peso: {p.get('MolecularWeight')}") pesquisar_molecula("caffeine")
Como usar: Acesse colab.research.google.com, crie um novo notebook, cole o código e pressione ▶️ Executar.
